Como rodar
Backend

Acesse a pasta do backend:

cd backend

Instale as dependências do Symfony:

composer install

Inicie o servidor:

symfony server:start

Dependências

Symfony 8.1
Doctrine ORM
Symfony Security
LexikJWTAuthenticationBundle 3.2.0
lcobucci/jwt 5.6.0
Web Token Suite 4.x
PostgreSQL

Frontend

Acesse a pasta do frontend:

cd frontend

Instale as dependências:
npm install
npm install @mui/material @emotion/react @emotion/styled
npm install @mui/icons-material
npm install react-router-dom
npm install axios
npm install zustand

Inicie o servidor de desenvolvimento:
npm run dev

Dependências
React
TypeScript
Material UI
Material UI Icons
React Router DOM
Axios
Zustand
